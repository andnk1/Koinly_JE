Transaction History

Your raw Koinly transaction_history export(s) for the period — the file straight out of Koinly, not a re-saved or edited copy. You can select more than one file (e.g. separate exports per quarter) and they'll be combined into one report.

GL Account Mapping

Maps each Koinly Tag/category (e.g. "Reward", "Cost", "Loan") to your real QuickBooks GL account. Two columns: Label and Account Name. Leave this blank to skip mapping — the report's GL Account column will just be empty for every line. Optional Default Digital Asset Account and Default Capital Gain/Loss Account rows replace the built-in "Digital Asset" and "Capital Gain/Loss" accounts; leave them blank to keep the built-in names.

Download default mapping (.csv)

This is a default mapping — a suggested starting point only. Before uploading it, change each Account Name to the exact account name in your QuickBooks chart of accounts (spelling and capitalization must match, or QuickBooks won't recognize it). Replace placeholders like "Ask Client" with the real account.

Reconciliation (Optional)

Your wallet/exchange balance at the very start of the period, from your own records (e.g. Koinly's or the exchange's statement). Optional — leave blank to treat it as 0.00; the report still runs either way.

The same balance at the end of the period. Optional — leave blank to treat it as 0.00. The Reconciliation tab compares this to what the transactions themselves calculate, and flags any difference.

Run

Produces one Excel workbook (Reconciliation, JE by Month, Total JE and Transaction History tabs) plus a separate QB_JE.csv ready to import into QuickBooks.

Nothing you upload is stored — files are processed in memory for this run only, and the generated report is held just long enough for you to download it.
